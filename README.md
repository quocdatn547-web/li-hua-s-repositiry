## 需要了解的重要内容（当前阶段）

## 后续学习建议（仓库启动后）

1. **补齐基础文档**：优先补充项目背景、运行方式、依赖环境、目录结构说明。
2. **建立模块边界**：尽快明确核心模块及其职责，配套架构图或模块说明。
3. **补充开发约定**：包括代码风格、分支策略、提交规范、测试与发布流程。
4. **逐步建立示例/测试**：为新人提供可运行的示例与最小测试集。
